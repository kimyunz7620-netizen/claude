# 5천만 원 플랜

빚 정리와 목돈 5천만 원 모으기를 위한 개인용 가계부·롯데카드 점검 앱이에요.
claude.ai 아티팩트로 동작합니다: https://claude.ai/artifact/ARaBL6enkxP2o2vfosGJmi

- `index.html`: 아티팩트 페이지 소스 (이 파일을 같은 링크로 다시 게시)
- `seed/`: 처음 넣은 데이터 (예산, 고정비, 할부표, 빚 목록, 설정)

## 저장 구조 (아티팩트 db)

| 경로 | 내용 |
|---|---|
| `config/settings` | 실수령, 인상률, 생활비·주간 한도, 보증금, 목표 |
| `config/budget` | 생활비 카테고리별 예산 (경조사/선물은 적립식) |
| `config/fixed` | 고정비 (변경 시작월 포함) |
| `config/schedule` | 롯데카드 결제월별 할부 합계표 (원본) |
| `plan/debts` | 상환 순서대로 정렬한 빚 목록 |
| `plan/tasks` | 날짜별 할 일 체크 |
| `entries/*` | 지출 1건씩 (날짜, 카테고리, 금액, 결제수단, 메모) |
| `days/{날짜}` | 습관 체크 4개와 하루 메모 |
| `weekly/{날짜}` | 주간 카드 점검 (카드 앱 이용금액·결제예정액) |
| `payments/*` | 선결제·상환 기록 (할부 청구액 감소분 포함) |
| `networth/{월}` | 월말 저축·현금 잔액과 그때의 순자산 |

계좌번호·카드번호는 저장하지 않아요.

## 계산 방식

- 카드 주기: 12일~다음 달 11일 사용분이 그 달 25일에 결제
- 예상 할부액 = 할부표 − 선결제로 줄어든 월 청구액 + 앱에서 새로 기록한 할부
- 예상 결제액 = 해당 주기 롯데 일시불 합계 + 그 달 예상 할부액
- 남은 빚 = 남은 카드 할부 합계 + NH 대출 + 마이너스통장
- 순자산 = 보증금 + 저축·현금 잔액 − 남은 빚
- 완납 예상: 매달 (실수령 − 고정비 − 생활비 − 할부액)을 상환 순서대로 넣는다고 보고 계산. 대출 이자는 고정비의 이자/수수료에 포함된 것으로 봄
