# 머니플랜

빚 정리와 순자산 1억 모으기를 위한 개인용 가계부·롯데카드 점검 앱이에요.
claude.ai 아티팩트로 동작합니다: https://claude.ai/artifact/ARaBL6enkxP2o2vfosGJmi

- `index.html`: 아티팩트 페이지 소스 (이 파일을 같은 링크로 다시 게시)
- `seed/`: 처음 넣은 데이터 (예산, 고정비, 할부표, 빚 목록, 설정)

## 저장 구조 (아티팩트 db)

| 경로 | 내용 |
|---|---|
| `config/settings` | 실수령(예상), 달별 실제 받은 실수령(`incomeActual`), 인상률, 생활비·주간 한도, 보증금, 목표 |
| `config/budget` | 생활비 카테고리별 예산 (경조사/선물은 적립식) |
| `config/fixed` | 고정비 (변경 시작월 포함) |
| `config/installments` | 롯데카드 할부 33건 (26년 11월 결제 기준: 회차, 월 원금, 수수료, 결제 후 잔액) |
| `config/schedule` | 결제월별 할부 합계표 (건별 목록이 없을 때만 사용) |
| `plan/debts` | 대출 (NH 직장인대출, 마이너스통장) |
| `plan/accounts` | 은행별 현재 잔액 (하나·케이뱅크·우리, 은행 이름만) |
| `plan/tasks` | 날짜별 할 일 체크 |
| `entries/*` | 지출 1건씩 (날짜, 카테고리, 금액, 결제수단, 메모) |
| `days/{날짜}` | 습관 체크 4개와 하루 메모 |
| `weekly/{날짜}` | 주간 카드 점검 (카드 앱 이용금액·결제예정액) |
| `payments/*` | 할부 건별 선결제(`itemId`, `fromYm`) · 대출 상환(`debtId`) |
| `coach/{날짜}` | 그날의 AI 코칭 (총평, 조언 3개, 미션, 미션 성공 여부) |
| `networth/{월}` | 월말 저축·현금 잔액과 그때의 순자산 |

계좌번호·카드번호는 저장하지 않아요.

글꼴은 SUIT(SUNN, SIL Open Font License 1.1)를 자주 쓰는 한글 2,350자와 영문만 남기고 줄여서(약 370KB) 페이지 안에 넣었어요. 아티팩트는 Google Fonts 외의 글꼴 주소를 막기 때문이에요. 드문 글자는 기기 기본 글꼴로 보여요.

## 계산 방식

- 카드 주기: 12일~다음 달 11일 사용분이 그 달 25일에 결제
- 할부 청구액 = 건별로 월 원금 + 월 수수료 (카드사 결제예정표와 월 1천~5천 원 차이)
- 선결제 추천 = 절약률(남은 수수료 ÷ 남은 원금)이 높은 건부터, 남는 돈으로 통째로 갚을 수 있는 건 우선
- AI 코치: 오늘 데이터를 JSON으로 Claude에게 보내고(`sample` 기능) 결과를 `coach/{날짜}`에 저장
- 예상 결제액 = 해당 주기 롯데 일시불 합계 + 그 달 예상 할부액
- 남은 빚 = 카드 할부 남은 원금 + NH 대출 + 마이너스통장
- 순자산 = 보증금 + 저축·현금 잔액 − 남은 빚
- 앞으로의 길: 아래 완납 계산을 빚이 끝난 뒤에도 이어서, 달마다 남는 돈 중 빚 갚는 돈과 모으는 돈을 나눠 그려요. 카드 할부 끝, 월급 인상, 빚 0원, 저축 시작, 반년·1년 저축액, 5천만·1억 도착 시점을 보여 주고, 대출이 끝나면 그 이자만큼 저축이 늘어난다고 봐요
- 완납 예상: 매달 (실수령 − 고정비 − 생활비 − 할부액)을 상환 순서대로 넣는다고 보고 계산. 대출 이자는 고정비의 이자/수수료에 포함된 것으로 봄
