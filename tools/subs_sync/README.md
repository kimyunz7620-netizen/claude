# 땅콩집 플래너 · 청약 공고 자동 동기화

집 노트북에서 하루 한 번 실행하면 청약 공고를 가져와서 땅콩집 플래너 앱의 "청약 공고 리스트"를 채워 줍니다.
폰에서는 앱만 열면 됩니다.

동작 방식
1. 공공데이터포털의 **청약홈 분양정보 API**로 서울·경기 APT 공고와 주택형(면적·세대수·분양가)을 가져옵니다.
2. 공고는 **서울·경기 전체, 평형 전체**를 가져오고 거르지 않습니다. 대신 앱 화면에 "희망 평형 있음/없음"(기본 전용 40~60㎡),
   "관심 지역 아님"(영등포·마포·강서·양천·동작 기준)을 표시하고, 조건에 맞는 공고를 위로 올립니다.
   소득·자격·청약통장은 알 수 없어서 "공고문 확인"으로 둡니다.
3. 크롬으로 앱을 열어 숙제 → 정책·청약 → "공고 가져오기"에 넣고 "리스트에 넣기"를 눌러 줍니다.

## 한 번만 하는 준비

1. **파이썬 설치 확인** (3.9 이상): `python3 --version`
2. **라이브러리 설치**
   ```
   pip install -r requirements.txt
   ```
   (크롬은 이미 설치된 것을 씁니다. `playwright install`은 필요 없어요.)
3. **인증키 받기**
   - 공공데이터포털(data.go.kr)에 가입하고 "한국부동산원_청약홈 분양정보 조회 서비스"를 검색해 **활용신청**합니다.
   - 마이페이지에서 **일반 인증키(Decoding)**를 복사합니다.
   - 터미널에 등록합니다: `export ODCLOUD_KEY="복사한키"` (Windows는 `setx ODCLOUD_KEY "복사한키"`)
4. **claude.ai 로그인 한 번**
   ```
   python3 subs_sync.py login
   ```
   크롬이 열리면 평소 쓰는 계정으로 claude.ai에 로그인하고, 앱 주소가 열리는지 확인한 뒤 **크롬 창을 모두 닫으세요.**
   (로그인 정보는 이 폴더의 `.chrome-profile`에만 저장되고, 깃에는 올라가지 않습니다.)

## 실행

```
python3 subs_sync.py fetch     # 먼저 공고만 가져와서 out/ 폴더에 JSON으로 저장 (앱에는 안 넣음)
python3 subs_sync.py run       # 가져와서 앱에 넣기
```
처음에는 `fetch`로 결과가 이상하지 않은지 보고 `run`을 쓰세요.
옵션: `--area-min 40 --area-max 60`, `--regions 서울,경기`(기본값), `--horizon 60`(며칠 안에 접수가 시작되는 공고까지)

## 매일 자동으로 돌리기

- **맥/리눅스 (cron)**: `crontab -e` 에 한 줄 추가 (매일 아침 7시)
  ```
  0 7 * * * cd /경로/tools/subs_sync && ODCLOUD_KEY="키" /usr/bin/python3 subs_sync.py run >> run.log 2>&1
  ```
- **윈도우**: 작업 스케줄러 → 기본 작업 만들기 → 매일 → 프로그램 `python`, 인수 `subs_sync.py run`, 시작 위치는 이 폴더.
- 실행 중에 크롬 창이 잠깐 뜹니다. 노트북이 켜져 있고 잠자기 상태가 아니어야 합니다.

## 문제가 생기면

- `API 오류`: 인증키(Decoding)와 활용신청 승인 상태를 확인하세요. 승인에 시간이 걸릴 수 있어요.
- 공고가 0건이거나 평형이 비어 있음: `python3 subs_sync.py fetch --raw` 로 API 필드 이름을 출력해서 알려 주세요.
- `로그인이 풀린 것 같아요`: `login`을 다시 실행하세요.
- `앱 화면을 찾지 못했어요`: 앱 주소가 맞는지(`--url`)와 해당 계정으로 앱이 열리는지 확인하세요.
- `--headless`(창 없이)는 로그인이 풀리기 쉬워서 권하지 않습니다.
